In this quickstart, you configure the reader's **Control** and **Tag Data 1** interfaces to use MQTT, start RFID inventory, and receive a tag observation in an MQTT client.

:::note
Configure, preview, and publish each interface separately, even when both interfaces use the same broker.
:::

## Before You Begin

- Complete the reader installation, sign in to the web console, set the regulatory region, and [verify readiness](./verify-reader-readiness-and-status.mdx).
- Have a compatible RFID test tag and a configured antenna in the read area.
- Have access to an MQTT broker and a client that can publish and subscribe. The reader and client must be able to reach the broker.
- Obtain the broker's connection details, credentials, and certificates if required. Choose topics and permissions for the Control and Tag Data interfaces.

## Step 1: Configure the Control Interface

1. In the reader web console, open **Settings > Endpoint** and select **Control**.
2. Set **Endpoint Type** to **MQTT** and enter the broker connection details.
3. On the **Topic** tab, configure the Control command and response topics.
4. Configure certificates if required, select **Preview** to review the settings, and select **Publish**.
5. Confirm that the Control interface shows **connected**.

For field descriptions and screenshots, see [Connect to an MQTT Broker](../connect-the-reader/connect-to-an-mqtt-broker.mdx).

## Step 2: Configure the Tag Data Interface

1. Select **Tag Data 1** and set **Endpoint Type** to **MQTT**.
2. Enter the broker connection details and configure the Tag Data topic on the **Topic** tab.
3. Configure certificates and batching and retention as needed.
4. Select **Preview**, review the settings for **Tag Data 1**, and select **Publish**.
5. Confirm that the Tag Data 1 interface shows **connected**.

Use a different MQTT client ID for each active connection to the same broker.

## Step 3: Subscribe to the Topics

Connect your MQTT client to the broker. Subscribe to the Control response topic and the Tag Data topic **before** sending the start command. Use the topic names configured for your deployment.

## Step 4: Start Inventory and Read a Tag

1. Configure an RFID operating mode suitable for a basic inventory, with the intended antenna enabled. Use the reader's operating-mode documentation for your model and firmware.
2. In your MQTT client, publish the following message to the **Control command topic**:

   ```json
   {
     "command": "start",
     "command_id": "quickstart-start-01",
     "payload": {
       "doNotPersistState": true
     }
   }
   ```

3. Check the Control response topic for the response with the matching `command_id` and confirm that the reader accepted the command.
4. Present the test tag to the antenna and check the Tag Data topic for an observation.

These examples use the fixed-reader [RAW MQTT command schema](https://zebradevs.github.io/rfid-ziotc-docs/_static/raw_mqtt_payloads/commands/redoc-static.html). Use a new `command_id` for each command.

## Step 5: Stop Inventory

Publish the following message to the same **Control command topic**:

```json
{
  "command": "stop",
  "command_id": "quickstart-stop-01",
  "payload": {}
}
```

Confirm the matching response on the Control response topic. After inventory stops, confirm that new tag observations stop arriving.

If no tag observation arrives, check the antenna and operating mode, confirm both interfaces are connected, and verify that the MQTT client is subscribed to the configured Tag Data topic.
