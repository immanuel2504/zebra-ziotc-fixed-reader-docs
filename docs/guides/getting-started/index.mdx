Set up your reader and prepare it to communicate with an application. Start with the integration guide for hardware installation and reader discovery, then use the web console to complete the initial checks.

When the reader is ready, follow the MQTT quickstart to configure the Control and Tag Data interfaces and receive your first tag observation.
