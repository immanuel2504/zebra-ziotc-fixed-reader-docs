Set up your reader and prepare it to communicate with an application. Start with the integration guide for hardware installation and reader discovery, then use the web console to sign in and configure the regulatory region, date, and time.

When the reader is ready, follow the MQTT quickstart to configure the Control and Tag Data interfaces and receive your first tag observation.
